# wing-syntax

## Features
* = unimplemented
### Keywords
- fn
    - Starts a function definition
    - usage: fn type name(...)
- while *
    - Makes a while loop
    - usage: while(condition)
- if *
    - Makes an if condition
    - usage: if(condition)
### Grammar
- Preprocessor (!) *
    - Adds a preprocessor the compiler will process before conversion
    - usage: !preprocessor_name
- Set (=) *
    - Sets the value of a named variable
    - usage: name = value
- Separator (,)
    - Separates arguments in a function
- End (;)
    - Ends a statement, each separate statement must end with this.
    - usage anything;
